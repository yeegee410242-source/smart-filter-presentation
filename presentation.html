APP FEATURES (PART 1)

스마트홈 웹 어플 핵심 기능 (홈 · 기기 · 리포트)

Smart Filter
1. 🏠 홈 (Home)
• 최상단 시스템 알림: 긴급/최근 알림 창 상단 배치
• 필터 막힘도 UI: 예상관리일·수명% 에너지효율등급형 시각화
• 위험도 분석: AI 곰팡이 & 오염가속 위험도
• 센서 새로고침: 수치 즉시 갱신 버튼
• 라이브 카메라: 실시간 필터 촬영 On/Off
• 실시간 센서: 차압, 온습도, 누적 운전시간
• 미세먼지 농도: 기상청 연동 대기 창
• 바로가기: 3분 회복 검증 이동 버튼
2. 💻 기기 (Device)
• 에어컨 등록 & 공간 선택: 주방/거실 등 공간별 수명 공식 차등 적용 (주방 기름때 반영)
• 가족 관리 (+반려동물): 털/오염 필터 수명 영향 반영
• 기기 상세 정보: 모델, 필터 종류, 설치일, 누적 운전시간, 연결 게이트웨이/신호
3. 📊 리포트 (Report)
• 라즈베리파이 실시간 절감 분석: 누적 절감 전력(kWh) & 누적 절감 전기요금(원) 집계
• 에너지 절감 집중화: 가동 그래프 제거 ➔ 오직 절감된 에너지 데이터 시각화 제공
APP FEATURES (PART 2)

스마트홈 웹 어플 핵심 기능 (회복테스트 · 관리 · 필터마켓)

Smart Filter
4. ⏱️ 회복 테스트
• 3분 세척 전후 검증: 3분 타이머 카운트다운 진행
• 종합 판정: 100점 만점 평가 리포트
• 테스트 결과: 차압 회복률, 전력 개선률, 풍량 회복률 수치화
• 항목 확인: 차압, 소비전력 확인 & 다시 테스트하기
5. ⚙️ 관리 (Management)
• 필터 이력: 관리 및 회복 데이터 이력 기록
• 센서 상태 체크: SDP610 차압 & BME280 온습도 정상작동 진단 및 이상 알림
• 기준값 재학습 실행: 차압/팬속도/교체주기 재학습 실행 기능
• 알림 임계값 설정: 주의 및 청소 권장 알림 기준 설정
6. 🛒 필터 마켓 (Market)
• 가장 오른쪽 탭 배치: B2B 연계 커머스 공간
• 필터 메인 상품배치: 전체상품 ➔ 필터(Main) ➔ 에어컨, 공기청정기, TV 등
• 기업 제휴 배너: 제조사 맞춤 정기배송 배너 광고 연동
